## 5. FAQ

**Q1: Agent Memory 与传统的 RAG（检索增强生成）有什么本质区别？**
A: 传统 RAG 依赖于静态的外部知识库，主要用于解决模型知识不更新或缺乏私有数据的问题，是只读的；而 Agent Memory 是动态的、与 Agent 状态绑定的，记录了交互历史、环境反馈和技能演进，支持读写、更新和遗忘。Agent Memory 是支撑智能体“持续学习”和“长程任务规划”的核心。

**Q2: 在 AI Agent 中使用知识图谱作为记忆层有哪些优势和挑战？**
A: 优势在于：1) 结构化表达实体间关系，提升多跳推理能力；2) 具备时间感知能力，可追踪状态变化；3) 相比向量检索，可解释性更强。挑战在于：1) 实体抽取和图谱构建增加了系统的计算延迟；2) 图谱的动态更新和冲突消解（如何遗忘和修正错误节点）在工程上极其复杂。

**Q3: 如何为 AI Agent 选择合适的长期记忆存储方案？**
A: 需基于业务场景决策：1) 若追求极简部署和单机应用，选择基于文件的本地方案（如 SQLite/Rekal）；2) 若涉及复杂关系推理，选择基于知识图谱的方案（如 HippoRAG 架构）；3) 若为企业级多智能体协作，需选择支持多资产类型（Chat/Doc/Code 统一管理）的团队级记忆中心（如 TencentDB Agent Memory）。

### Q: Agent Memory 系统当前最大的工程挑战是什么？
A: 记忆管理——写入过滤（什么值得记）、压缩整合（避免无限增长）、遗忘机制（过时信息降权）、冲突消解（矛盾记忆处理）。大部分系统只解决了存取，未解决管理。

### Q: RAG 和 Memory System 的本质区别是什么？
A: RAG 是 Memory 的 L2 检索层实现，只解决相关性匹配。完整 Memory System = L1 存储 + L2 检索 + L3 推理 + 主动记忆管理策略。RAG 是必要但不充分的组件。

A: 记忆推理层（L3）——决定何时用哪段记忆、多段记忆间如何推理、记忆冲突如何消解。这是区分「有记忆的 Agent」和「会记忆的 Agent」的关键。
