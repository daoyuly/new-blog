|------|------|---------|--------|
| L1 存储层 | 向量存取 | Embedding + ANN | ⭐⭐⭐⭐ 已成熟 |

**Q1: Agent Memory 和传统 RAG 有什么区别？**
A: 传统 RAG 是静态的“外部知识检索”，数据源与 Agent 当前任务通常无直接关联；Agent Memory 是动态的“经验记忆”，记录的是 Agent 自身的推理历史、环境交互和技能沉淀。现代 Agent 架构（如 OpenViking）正将两者融合为统一的自进化上下文数据库。

**Q2: 如何解决长程任务中 Agent 记忆爆炸导致的 Token 超限问题？**
A: 需要引入记忆压缩与遗忘机制。工程上可采用分级处理：近期上下文保留原文，中期历史使用 LLM 摘要器（如 SUMONE）进行压缩，远期历史提取为实体/关系图谱或技能规则。同时可应用模型量化技术（如 bf16）降低底层推理成本。

**Q3: 给 AI Agent 添加长期记忆，最简单的技术栈是什么？**
A: 最轻量级的方案是“文件系统 + 本地数据库”。将 Agent 的对话和总结写入本地 SQLite（如开源项目 Rekal）或结构化 Markdown/Obsidian 库（如 obsidian-mind）。配合轻量级 Embedding 模型进行本地检索，即可实现零云端依赖的持久化长期记忆。
