## 会面地点：牡丹园区域

### 选址理由

1. **老刘零换乘**：牡丹园站就在 10 号线上，老刘从国贸直达，无需换乘
2. **距离可控**：小关 2 次换乘但总计仅 5 站，约 18 分钟
3. **餐饮丰富**：牡丹园是成熟商圈，多家口碑老店
4. **适合谈事**：餐厅选择多，有包间/安静位的选项

---

## 交通方案

### 老刘：国贸 → 牡丹园

```
10号线 国贸 → 牡丹园（直达，无需换乘）
  路径：金台夕照 → 呼家楼 → 农业展览馆 → 亮马桥 → 三元桥
        → 太阳宫 → 芍药居 → 惠新西街南口 → 安贞门
        → 北土城 → 健德门 → 牡丹园
```

- 总计：12 站，**0 次换乘**，约 28 分钟
- 出站：牡丹园站

### 小关：关庄 → 牡丹园

```
15号线 关庄 → 奥林匹克公园（2站）
换乘8号线 奥林匹克公园 → 北土城（1站）
换乘10号线 北土城 → 健德门 → 牡丹园（2站）
```

- 总计：5 站，2 次换乘，约 18 分钟
- 出站：牡丹园站

> 老刘虽然站数多但不用换乘，小关站数少但需 2 次换乘。两人耗时接近，牡丹园站集合。

## 餐厅推荐（3 选 1）

### 🥇 首选：北平楼 · 烤鸭 · 北京菜（牡丹园店）

| 项目 | 内容 |
|------|------|
| 地址 | 海淀区牡丹园（花园东路） |
| 人均 | ~110 元 |
| 评分 | 4.7 / 5（162+ 条点评） |
| 类型 | 北京菜 / 烤鸭 |
| 营业时间 | 10:30 - 20:30 |
| 设施 | 空调、等位区、大桌、免费 WiFi、付费停车、宝宝椅、宴会厅 |

**推荐理由**：北京菜老店，有宴会厅/大桌，适合 2 人安静谈事。烤鸭是招牌，菜品地道。评分高，环境成熟。人均 110 略超预算但可接受。

### 🥉 备选 B：峨嵋酒家（牡丹园店）

| 项目 | 内容 |
|------|------|
| 地址 | 海淀区牡丹园 |
| 类型 | 川菜 / 峨嵋菜 |
| 人均 | ~90-100 元 |

**推荐理由**：华天老字号川菜馆，口味正宗。如果两人偏好辣味，是不错选择。环境相对安静，适合谈事。

## 注意事项

- 周五晚牡丹园商圈人流量大，**建议提前电话预约**
- 北平楼有宴会厅，可电话沟通安排安静位置
- 聚宝源涮肉店周五晚高峰可能等位，建议提前到或预约

- 牡丹园站出口较多，提前确认去哪个餐厅、从哪个口出
