# ReAct 开源项目研究报告

## 1. 项目概述

ReAct（Reasoning + Acting）是普林斯顿大学与 Google 研究者发布的 ICLR 2023 论文官方代码库，提出了大语言模型提示工程的经典范式：**让模型交替生成推理轨迹和面向任务的行动**，从而协同解决复杂问题。

核心价值在于将“思维链推理”与“环境交互行动”统一在一个提示框架内：模型先思考，再采取行动（如调用搜索、查询知识库），观察行动结果后继续推理，形成 Thought → Action → Observation 的循环。这一范式成为后续 Agent（智能体）研究的基础，被 LangChain 等主流框架直接采纳。

主要功能：
- 四个任务基准的完整实验 notebook：HotpotQA（多跳问答）、FEVER（事实验证）、AlfWorld（具身家务任务）、WebShop（网页购物）
- 基于 GPT-3 (davinci-002) 与 PaLM-540B 的 prompt 模板与 few-shot 示例
- 标准化的评测脚本（EM、成功率）与结果解析逻辑

## 2. 技术栈分析

**技术框架**：
- Python + Jupyter Notebook 为主体（46 个文件中 notebook 占多数，研究型代码风格）
- `openai` SDK：调用 GPT-3 completion API
- `alfworld`：具身环境模拟器
- 检索类任务依赖 HotpotQA/FEVER 的 Wikipedia 语料检索接口

**架构特点**：
- 无复杂工程框架，采用“提示模板 + 解析器 + 环境”的轻量三层结构
- Prompt 设计为核心资产：控制流（Thought/Action/Observation 标签）完全嵌入提示文本，由模型自回归生成
- 范式统一：同一个循环结构适配文本推理任务（HotpotQA/FEVER）与交互式环境任务

**依赖关系**：极简，仅 openai 与任务环境包，符合论文复现代码的定位。

## 4. 技术实现亮点

- **推理与行动协同**：相比纯 CoT（易幻觉）和纯 Act（缺长期规划），ReAct 用推理引导行动、用行动获取外部事实反馈修正推理，双向增强
- **提示即程序**：整个 Agent 控制流通过 few-shot 示例编码在 prompt 中，是"prompt as program"的早期典范
- **可解释性**：显式 Thought 让决策过程人类可读、可调试
- **消融设计**：代码天然支持 CoT-only / Act-only / ReAct 对照，便于理解各成分贡献
- **跨域通用性**：同一范式覆盖知识密集型 NLP 与具身决策两类截然不同的任务
