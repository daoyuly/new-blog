| 层级 | 功能 | 工程实现 | 成熟度 |
|------|------|---------|--------|
| L1 存储层 | 向量存取 | Embedding + ANN | ⭐⭐⭐⭐ 已成熟 |

## 5. FAQ：关于 Agent Memory 的常见问题

**Q1: Agent Memory 与传统 RAG 系统的区别是什么？**
A: 传统 RAG 侧重于“外部知识的静态检索”，而 Agent Memory 侧重于“交互经验的动态积累”。Memory 系统不仅存储事实，还存储 Agent 过去的推理路径、工具使用结果及用户偏好，并能进行遗忘、更新和技能固化，是 Agent 实现自我进化的前提。

**Q2: 知识图谱在 Agent Memory 中扮演什么角色？**

**Q3: 如何在工程上平衡 Agent 的记忆容量与上下文窗口限制？**
