M4是这6个月里技术跨度最大的一个月。前三个月你一直在研究：

> **模型如何变成 Agent，以及 Agent 如何可靠地完成任务。**

M4开始切换视角：

> **模型本身是怎么运行的？为什么 GPU 决定了 LLM 的性能？Inference Runtime 又是怎么把 GPU 吃满的？**

考虑到你后面还计划用一年深入 LLM 推理，M4不应该试图“一个月学完 GPU”。正确目标是建立一套足够扎实的 **GPU + Transformer Inference + Serving** 基础，并通过实验形成直觉。

# M4特别需要掌握的公式

这个月不要求做复杂推导，但下面几个量必须能够自己算。

### 模型权重显存

粗略：

```text
Memory ≈ Parameters × Bytes per Parameter
```

例如：

```text
7B × 2 bytes ≈ 14GB
```

这是FP16/BF16的粗略估算，不包括其他运行时开销。

---

### KV Cache

核心变量：

```text
Batch
×
Sequence Length
×
Layers
×
KV Heads
×
Head Dimension
×
2(K,V)
×
Bytes
```

你应该能够拿到一个模型配置后自己估算 KV Cache。

---

### Throughput

```text
Throughput
=
Generated Tokens / Second
```

---

### TTFT

```text
Time To First Token
```

主要受：

```text
Prefill
```

影响。

---

### TPOT

```text
Time Per Output Token
```

主要反映：

```text
Decode
```

性能。

# M4月底能力标准

M1：

> 我可以自己实现 Agent Runtime。

M2：

> 我可以让 Agent 在 Sandbox 中完成 Coding Task。

M3：

> 我可以控制 Context，并设计 Task-aware Memory。

M4应该达到：

> **我可以解释一个 LLM Inference 系统从 GPU、Attention、KV Cache 到 Scheduler、Batching、Serving 的完整性能链路。**

也就是说，你的知识结构开始变成：

```text id="31sv5r"
                 AI Agent
                    │
        ┌───────────┴───────────┐
        │                       │
   Agent Systems            AI Systems
        │                       │
 Runtime/Harness          GPU/Inference
 Context                  KV Cache
 Memory                   Attention
 Tool                     Batching
 Environment              Serving
 Evaluation               Distributed
        │                       │
        └───────────┬───────────┘
                    │
                 M5
                    ↓
          Evaluation / RL /
          Agent Research
```

有一点需要特别控制：**M4不要试图把CUDA、GPU架构、Transformer、vLLM、SGLang、分布式推理全部学深。** 这一个月的目标是建立完整的“性能因果链”，而不是完成GPU专业课。

你后面一年深入推理时，再逐层下钻：

**GPU Architecture → CUDA Kernel → Attention Kernel → KV Cache → Serving Scheduler → Parallelism → Inference Optimization。**

这样M4结束后，M5才能自然进入 **Agent Evaluation → Trajectory → Reward → RL / Agent Training → Research Engineering**，而不是重新开始一条完全割裂的学习线。
