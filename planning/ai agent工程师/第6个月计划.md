# Day 2：Agent State & Persistence

Production Agent 最大的问题之一：

> Agent 运行到一半挂了怎么办？

实现：

```text
State
Checkpoint
Resume
```

例如：

```python
state = {
    "task_id": "...",
    "step": 7,
    "messages": [...],
    "tool_results": [...],
    "status": "running"
}
```

支持：

```bash
agent run task.json
agent resume task_id
```

实验：

```text
Step 1
Step 2
Step 3
↓
Process Kill
↓
Restart
↓
Resume Step 3
```

目标：

**不能因为进程重启而丢失任务状态。**

# Day 3：Idempotency

Agent 很容易出现：

```text
模型
 ↓
Tool Call
 ↓
网络超时
 ↓
Agent 不知道 Tool 是否成功
 ↓
Retry
 ↓
重复执行
```

例如：

```text
发送邮件
创建订单
删除文件
支付
```

学习：

* Idempotency Key
* Request ID
* Retry semantics
* At-least-once execution

编码：

```python
tool.execute(
    request_id="task123-step4"
)
```

同一个 request_id 重复执行时：

```text
第一次：真正执行
第二次：返回已有结果
```

# Day 5：Concurrency

Agent Runtime 不应该只有：

```python

```

```text

```

```text
                    Queue
                      │
        ┌─────────────┼─────────────┐
        ↓             ↓             ↓
     Worker 1      Worker 2      Worker 3
        ↓             ↓             ↓
      Agent          Agent         Agent
```

测试：

```text

50 tasks
100 tasks
```

观察：

```text
Throughput
Latency
CPU
Memory

```
